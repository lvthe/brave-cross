Đặc tả RPC Búa Tạ

Toàn bộ bề mặt giao tiếp client–server, trích tự động từ — file Lua đã giải mã khỏi APK. Mỗi dòng dưới đây tương ứng một hàm server phải hiện thực, kèm chữ ký tham số, handler trả kết quả và vị trí trong mã nguồn gốc.

01 — Giao thức

Envelope protobuf, payload JSON, định tuyến theo tên hàm

Không có mã opcode. Client gửi thẳng tên hàm server cần gọi trong trường funcName, tham số nằm ở data dưới dạng mảng JSON. Server trả kết quả bằng cách gọi ngược lại một hàm của client theo đúng cơ chế đó. 

// conf/kGameRequestData.proto
message GameActionData {
  optional int32  module   = 1;  // nhóm server (§02)
  optional string funcName = 2;  // TÊN hàm server sẽ chạy
  optional int64  uid      = 3;
  optional string sessionId= 4;
  optional string data     = 5;  // mảng JSON tham số
  optional uint32 connId   = 6;
  optional uint64 IP       = 7;
  optional string objName  = 8;  // "" = hàm toàn cục
  optional uint64 serialID = 9;  // khớp req ↔ resp
  optional uint32 serverID = 10;
}
→

Client gọi và không chờ. CallServer(module, objName, funcName, ...) gói tham số bằng cjson.encode({...}) rồi gửi đi. rpc.lua:155

←

Server chủ động trả về. Kết quả không đi theo lời gọi cũ mà là một RPC ngược hoàn toàn mới: CallLocal(objName, funcName, data) → func(obj, unpack(cjson.decode(data))). rpc.lua:39, 84

←

Hình dạng payload trả về. Mọi handler kiểm tra tData.err ~= 0 trước tiên, rồi mới đọc tData.data. Mã lỗi liệt kê ở §03.

-- ví dụ trọn vẹn một vòng
CallServer(SERVER.GAME_LOGIC, "", "ClientUpgradeBuilding", nBuildingId)
  → data = "[12]"
  ← CallLocal("", "OnUpgradeBuilding", '[{"err":0,...}]')

02 — Định tuyến

Chín trong mười chín nhóm server thực sự được dùng

Hằng số SERVER lấy từ sc/share/Protocol.lua. Cột phải là số API client thực sự gọi tới nhóm đó.

03 — Bề mặt API

Danh mục hàm server

Kiểu tham số suy ra từ quy ước Hungarian của chính codebase (n/dw số, sz/str chuỗi, t bảng, b boolean, u uid). Phần mô tả là comment tiếng Trung nguyên bản của tác giả. Bấm một dòng để xem chi tiết.

tên hàm — client gọi lên
handler — server gọi ngược
n× — số chỗ gọi trong client

04 — Mã lỗi

Trường err, gom theo dải số

Trích từ sc/share/error.lua. Mỗi phân hệ chiếm một dải riêng — nghiệp vụ chung từ 500, thế giới game từ 1001, đăng nhập từ 1050, gateway từ 1080.

Nguồn. Số liệu sinh tự động từ mã nguồn Lua đã giải mã, không suy đoán thủ công. Lời gọi nằm trong comment đã bị loại; tầng vận chuyển sc/system/rpc.lua không tính là API.
